# Deck Layout Reference

Detailed slide types, layouts, and sequencing for presentations. Read the main SKILL.md first for narrative structure and quality gates, and `brand/brand_guidelines.md` for colours, typography, and tone.

## Format and Structure

**Aspect ratio**: 16:9 (widescreen)
**Content density**: 60-70% per slide — more breathing room than one-pagers
**Slide count guidance**: A typical pitch deck runs 8-15 slides. Don't pad — every slide must earn its place.

### The One-Thing-Per-Slide Rule
Each slide delivers exactly one message. The slide title IS that message — a complete, assertive sentence. Everything else on the slide is evidence supporting that single message.

### Narrative Sequencing
Follow the five-beat structure, but each beat may span multiple slides:

| Beat | Typical slides | Colour accent |
|------|---------------|---------------|
| Context / Problem | 1-2 slides | Deep Navy top accent |
| Pain | 2-3 slides | Warm Coral top accent (4px bar) |
| Solution | 2-4 slides | Teal top accent (4px bar) |
| Proof / Value | 2-3 slides | Amber Gold top accent (4px bar) |
| CTA / Close | 1 slide | Brand Green full background |

Bookend with dark slides: Title slide (Brand Dark background) and CTA slide (Brand Green background). Content slides are white/light.

## Slide Types

### 1. Title Slide
**Background**: Brand Dark (`#073914`)
**Purpose**: Set the tone, state the core proposition

- Logo (icon variant, white, 60% opacity) — top left
- Context label — small, uppercase, Amber Gold, letter-spacing 0.1em (e.g. "FOR THE COUNCIL FOR LICENSED CONVEYANCERS")
- Main title — ExtraBold (800), white, 36-44pt. Two lines. Key phrase in Amber Gold.
  - Example: "Compliance inspection / shouldn't be a *bottleneck.*"
- Subtitle — Regular weight, white at 45% opacity, max 70% width
- Subtle visual: Radial gradient from Brand Green (25% opacity) in top-right quadrant. Optional decorative circle (2px, white at 6% opacity).

### 2. Context/Problem Slide
**Background**: White
**Purpose**: Establish the situation the audience recognises

- Title: Bold sentence stating the context (e.g. "UK regulatory bodies inspect thousands of practices with limited capacity")
- Body: 2-3 short paragraphs OR a visual framework (e.g. org diagram, ecosystem map)
- Optional: Full-width image or diagram with overlay text
- Bottom: 2px Brand Green line

### 3. Pain Slide (Statistics)
**Background**: White
**Top**: 4px Warm Coral bar
**Purpose**: Quantify the problem with data

- Title: Bold sentence with the key pain insight (e.g. "Manual inspection is consuming 73% of your team's capacity on document review alone")
- **Layout: 3-column stat display**
  - Each column: Large stat number (48-72pt, ExtraBold, Coral) → Small label below (Muted)
  - Separated by 1px vertical Border Light lines
  - Example: "40+" / "3 wk" / "19" with labels
- **Insight box** at bottom: Coral Light background, 3px Coral left border, small text
  - Lead with "**Implication:**" in bold coral, then the so-what statement
- Bottom: 2px Brand Green line

### 4. Pain Slide (Qualitative)
**Background**: White
**Top**: 4px Warm Coral bar
**Purpose**: Describe the human/operational pain behind the numbers

- Title: Bold sentence describing the consequence
- **Layout: Icon + text rows** (2-3 rows)
  - Each row: Circular icon (44px, Coral) → Bold subtitle + description paragraph
  - Icons should represent specific pain points (time, documents, inconsistency)
- Bottom: 2px Brand Green line

### 5. Solution Overview Slide
**Background**: White
**Top**: 4px Teal bar
**Purpose**: Show the high-level approach

- Title: Bold sentence framing the solution (e.g. "Sumplexity automates the analysis, so inspectors focus on judgement")
- **Layout options (choose based on complexity):**
  - **Chevron flow (preferred)**: 3-4 angled chevron/arrow shapes pointing right, each containing an icon and label. Chevrons use Teal → Brand Green → Deep Navy colour progression to show advancement. This is the signature Sumplexity process visual — it creates momentum and looks distinctive.
  - **Connected hub**: Central circle ("Sumplexity") with 3-4 satellite circles connected by curved lines, each representing a capability. Good for showing interconnection rather than sequence.
  - **Circular flow**: Steps arranged in a curved arc or partial circle rather than a straight line. Each step is a node with an icon, connected by curved paths.
  - **Simple node flow (fallback)**: Horizontal nodes connected by arrows. Use progressively darker circles (Teal → Brand Green → Deep Navy).
- Bottom: 2px Brand Green line

### 6. Solution Detail Slide
**Background**: White
**Top**: 4px Teal bar
**Purpose**: Deep dive on a specific capability

- Title: Bold sentence stating what this capability delivers
- **Layout options**:
  - **Split**: Left 50% text (2-3 bullet points with bold leads), Right 50% screenshot/mockup/diagram
  - **Full visual**: Product screenshot or diagram with annotated callouts
  - **2×2 grid**: Four capability cards with icon + title + one-line description
- Bottom: 2px Brand Green line

### 7. Proof / Value Slide
**Background**: White
**Top**: 4px Amber Gold bar
**Purpose**: Demonstrate outcomes and credibility

- Title: Bold sentence stating the outcome (e.g. "10× faster document review with full evidence traceability")
- **Layout options**:
  - **Before/After comparison**: Two columns with contrasting metrics
  - **Value card grid**: 2×2 with checkmark icons (Amber Gold circles) + title + description
  - **Testimonial/quote**: Large pull quote with attribution (if available)
  - **Metric dashboard**: 3-4 large KPIs with trend indicators
- Bottom: 2px Brand Green line

### 8. CTA / Close Slide
**Background**: Brand Green (`#0A4D1C`)
**Purpose**: Drive the specific next action

- Title: ExtraBold, white, 32-40pt. Key phrase in Amber Gold.
  - Example: "Let's run a *pilot inspection* together."
- Subtitle: Regular weight, white at 50% opacity, max 75% width
  - Example: "We'll process real practice documents and show you findings side-by-side with your current approach. Zero commitment."
- Button: White background, Brand Green text, Bold, border-radius 4-5px, centred
- Logo (icon variant, white, 25% opacity) — bottom right
- Subtle radial gradient from Amber Gold (10% opacity) in bottom-right

## Visual Language — Beyond Boxes

Sumplexity decks should feel dynamic, not like a grid of rectangles. Every slide should have at least one non-rectangular visual element.

### Shape vocabulary
- **Chevrons / arrows**: The primary process-flow shape. Angled shapes that point right, creating forward momentum. Use for any sequential information (workflows, timelines, roadmaps).
- **Circles and rounded elements**: The Sumplexity signature — echoes the logo's circular data-burst. Use for: icon containers, stat callouts, hub diagrams, node-based flows.
- **Hexagons**: Good for capability grids and feature showcases. More interesting than rectangles, connotes technology.
- **Overlapping circles (Venn)**: For showing convergence, integration, or where Sumplexity sits at the intersection of ideas.
- **Pill/capsule shapes**: For tags, labels, and category markers.
- **Rounded cards with offset elements**: Cards where an icon or stat "breaks out" of the card boundary — partially overlapping the edge — create visual depth.

### Flow and momentum
- Slides should have directional energy. Use shapes that point rightward or downward to guide the eye.
- Curved connectors between elements feel more modern than straight lines or arrows.
- Staggered/offset layouts (e.g. cards at different heights in a row) create rhythm and avoid the "spreadsheet" look.
- On data slides, use a subtle curved or angled divider between the stat area and the insight box, rather than a flat line.

### What to avoid
- Perfectly symmetrical, axis-aligned layouts on every slide — vary the composition.
- Flat bullet lists in rectangles — convert to icon rows, chevron flows, or card grids.
- Sharp 90° corners on all elements — use rounded corners (6-8px) or fully circular shapes.
- Stock-photo-style imagery that adds no information. If you need an image, make it a diagram, screenshot, or icon illustration.

## Layout Principles

### Margins and Spacing
- Slide margins: 0.5" minimum from all edges
- Title to content gap: 0.3-0.4"
- Between content blocks: 0.3-0.5"
- Inside cards/boxes: 12-16px padding

### Text Rules
- Titles: left-aligned (never centred on content slides; centred OK on Title and CTA slides)
- Body text: left-aligned, max 70% slide width for readability
- No more than 3 text hierarchy levels per slide
- If a bullet point exceeds 2 lines, split the slide or cut the text

### Visual Variety
Vary the layout across slides. Don't repeat the same layout pattern on consecutive slides. Alternate between:
- Stat-heavy slides and narrative slides
- Left-heavy and right-heavy compositions
- Full-width and split layouts
- Dark and light backgrounds (use dark sparingly — title + CTA only by default)

### Data Visualisation
When charts or graphs are needed:
- Use Brand Green as the primary data colour
- Use accent colours for secondary series (Teal, Amber Gold)
- Keep charts clean — no gridlines, minimal axis labels
- The chart title should state the insight, not describe the data (e.g. "Revenue growth outpaces market by 15%" not "Revenue chart")

## Adapting Deck Length by Audience

| Audience | Target slides | Notes |
|----------|--------------|-------|
| Regulator | 8-10 | Focus on workflow fit, compliance rigour, evidence quality |
| Law firm | 6-8 | Shorter, more commercial, demo-focused |
| Investor | 12-15 | Include market, team, traction, financials |
| Partner | 8-12 | Include integration architecture, API readiness, mutual value |

## Common Deck Mistakes

- **Topic titles instead of message titles** — "Our Solution" tells the audience nothing. "Sumplexity automates document analysis so inspectors focus on judgement" tells them everything.
- **Text walls** — if a slide has more than 6 lines of body text, split it into two slides
- **Inconsistent accent colours** — don't use coral on a solution slide or teal on a pain slide. Colours map to narrative beats.
- **Missing insight boxes** — every data slide should have a "so what?" implication box
- **Weak CTA slide** — must be specific ("Book a 30-min demo") not vague ("Learn more")
- **Forgetting the green brand line** — it appears at the bottom of every content slide
- **Same layout repeated** — vary between stat, icon-row, split, and grid layouts
- **All-rectangular layouts** — every slide should have at least one non-rectangular element (circle, chevron, hexagon, curved connector). If it looks like a spreadsheet, redesign it.
- **Decorative elements with no purpose** — every visual should support the message. No stock photos of "people in a meeting."
