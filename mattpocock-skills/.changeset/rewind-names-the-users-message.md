`prepare-rewind` tells the user where to rewind in their own messages, since a rewind menu lists only those: "I said ..., then you said ...", naming the user's first message after the rewind point by its first words, to be replaced by the carry-on command. `implement` names its rewind point as the agent's own message and leaves the user's message to `prepare-rewind`.
